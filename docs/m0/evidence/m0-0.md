## Revisão `CHK-SEC` aplicável a M0.0

Esta foi revisão de desenho, não auditoria de implementação inexistente:

- SEC-006/007: layout separa candidates; assets são locais; comandos vindos de JSON e navegação remota são proibidos;
- SEC-011: raw/resumos são redigidos; traces sensíveis ficam locais/temporários e somente hashes entram no Git;
- SEC-012/013: package/associação não foram alegados e continuam bloqueados até M0.9;
- SEC-014: versões e modelos de licença foram inventariados; advisories/SBOM dependem dos manifests/lockfiles reais;
- SEC-015: C++/FFI e boundary QML continuam riscos explícitos, com paridade de gate para IPC Tauri;
- ausência de egress é separada de funcionamento offline e será provada por deny/captura + inspeção.

Nenhum controle de runtime foi marcado como aprovado apenas pela documentação.
