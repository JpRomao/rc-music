RC Music Windows x64 multimedia notices

FFmpeg 7.1.5-rcmusic2

RC Music uses the FFmpeg libraries avcodec-61.dll, avformat-61.dll,
avutil-59.dll, swresample-5.dll and swscale-8.dll through Qt Multimedia.
Copyright (c) the FFmpeg developers. The libraries are licensed under the GNU
Lesser General Public License version 2.1 or later. The shared-library build
has GPL, nonfree and version 3 components disabled. See FFmpeg-COPYING.LGPLv2.1.txt,
FFmpeg-LICENSE.txt and FFmpeg-CREDITS.txt.

The upstream source is FFmpeg n7.1.5, commit
3a0867c2bfda4a4d4309ca1a8cbdc6175e67f587.
https://codeload.github.com/FFmpeg/FFmpeg/tar.gz/refs/tags/n7.1.5
SHA-256 e3963a50831c985933e1a625ed566ec4c7adb5c012c34fa9f84438e1d61bdacc

The RC Music build applies four upstream changes to that source.

- The ADX decoder syncs its channel state when reading a new header and clears
  its predictor state when the channel count changes.
  CVE-2026-64835, libavcodec/adxdec.c
  https://github.com/FFmpeg/FFmpeg/commit/1836ef96846937a6cc2443698a693104f5c0b21e
- The VobSub demuxer reuses subtitle streams by ID and caps the stream count.
  CVE-2026-64830, libavformat/mpeg.c
  https://github.com/FFmpeg/FFmpeg/commit/dbd495f066a85ba96b17433f4306582aa37c3951
- The RASC decoder checks that 32-bit delta accesses fit in the row.
  CVE-2026-58049, libavcodec/rasc.c
  https://github.com/FFmpeg/FFmpeg/commit/11ff18a6c80187405fc492f9bb07ba9f2f663f76
- The IAMF parser checks the label count against the available bytes before
  allocating the label array.
  CVE-2026-66037, libavformat/iamf_parse.c
  https://github.com/FFmpeg/FFmpeg/commit/86708357d126af84c16f80d9c57335d1e8c845c5

The Windows x64 build uses MSVC 19.44.35228, Windows SDK 10.0.22621.0,
GNU Make 4.4.1 and NASM 3.02. It follows the Qt 6.11.2 Windows FFmpeg recipe,
with REVISION=7.1.5 and EXTRA_VERSION=rcmusic2 set for the build. The install
prefix and zlib build paths in the configuration are relative.
https://github.com/qt/qt5/blob/v6.11.2/coin/provisioning/common/windows/install-ffmpeg.ps1

zlib 1.3.1

The FFmpeg build uses an altered zlib 1.3.1, linked statically in
avcodec-61.dll and avformat-61.dll. Copyright (C) 1995-2022 Jean-loup Gailly
and Mark Adler. See zlib-LICENSE.txt. FFmpeg's libavutil/adler32.c is also
based on zlib code and retains the original notice of Mark Adler (1995).

https://github.com/madler/zlib/releases/download/v1.3.1/zlib-1.3.1.tar.gz
SHA-256 9a93b2b7dfdac77ceba5a558a580e74667dd6fede4585b91eefb60f03b72df23

The build applies the upstream inflateSync fix to inflate.c (TOB-ZLIB-004).
The Qt Windows build adjustments remove the unistd.h include from zconf.h
and the preferred base-address option from win32/Makefile.msc. The zlib
static library is built with the MSVC /MT option.
https://github.com/madler/zlib/commit/8179479c6274c0041189882b8746a33e2376eaf0
https://github.com/qt/qt5/blob/v6.11.2/coin/provisioning/common/windows/zlib.ps1

This notice accompanies a private development build. The matching source
