RC Music Windows x64 libdatachannel notices

RC Music uses the libdatachannel 0.24.6 shared library datachannel.dll for
the peer-to-peer data channels of the listening room ("Ouvir junto"). It is
present only in runtimes built with the listening room. libjuice, usrsctp,
plog and Mbed TLS are linked statically inside datachannel.dll.

The MPL-2.0 source files of libdatachannel and libjuice are used unmodified;
their source code is available at the addresses above. Mbed TLS is built from
the unmodified release with a separate configuration file
(MBEDTLS_USER_CONFIG_FILE) that turns MBEDTLS_SSL_DTLS_SRTP on and
MBEDTLS_SSL_PROTO_TLS1_3 off. The Windows x64 build uses MSVC 14.44, Release,
USE_MBEDTLS=ON, NO_MEDIA=ON, NO_EXAMPLES=ON and NO_TESTS=ON; the json and
libsrtp submodules are not used.
