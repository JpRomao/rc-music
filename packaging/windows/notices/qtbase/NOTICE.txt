Optional download worker TLS plugin

The optional download profile carries private copies of Qt Core and Qt
Network. Its manifest identifies the bytes for each copy. The accompanying
qrcmusicschanneloffline.dll is derived from the Qt Base 6.11.2 Schannel and
shared TLS sources, with local changes to certificate revocation handling
and a 262,144-byte TLS input limit. Its prepared source and build receipts
identify the derived files and the original Qt inputs.
